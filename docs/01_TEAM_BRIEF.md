# Mneme-Asterion：一分钟理解

**先记下来，再找证据，最后检查这些记忆现在是否仍然有效。**

1. **写入与建库**：沿用 AMI，把历史对话转成事实、更新记录和向量索引，同时保留原文与来源。
2. **检索与补证**：先取基础证据；发现缺少人物关系、时间锚点或列表成员时，再从原文检索并补充经过引用核验的片段。
3. **撤回与恢复**：P2 过滤被撤回的内容；V4进一步按“谁的哪项属性”处理状态，防止旧值从其他副本回来，并识别明确的新授权。

例如：先说“我的项目颜色是紫色”，后说“忘记我的项目颜色”，查询时返回撤回状态；“如果明天确认再记住”仍不算恢复；后来明确说“重新记住，我的项目颜色是琥珀色”，才允许使用新值。其他未撤回属性继续保留。

V4 是 P2 的状态管理增强。没有明确状态指令时保持 P2 路径；不是每道静态问答都触发 V4。它在检索输出层管理有效性，不会物理删除数据库中的原文。
