# P2：给队友的一页说明

**一句话：在 AMI 找到的记忆之上，补充有原文出处的缺失证据，并阻止已撤回的个人信息继续影响回答。**

1. 写入不另起炉灶：沿用 AMI 提取事实、保存原文、建立向量索引和处理更新；额外保存可追溯原始消息。
2. 检索先用 AMI：发现材料不够时，再用最多三个检索词找原文及邻接消息。选证据时明确人物、关系和所需操作；必须能在原文找到逐字引用。
3. 输出前处理撤回：识别“不要再记住/使用某属性”的有效请求，移除相关片段；需要时加入不含旧值的状态说明，避免回答模型猜回已撤回偏好。

为什么值得保留 P2：在同一冻结记忆库上比较 B0、E、R1Q、P2，减少建库随机波动。两组五 seed 中，P2 的七能力均分分别为 **60.51±3.81、62.40±3.36**，均为四方法最高，比 B0 高 **3.15、2.65 个百分点**。全部 7,712 题次已评分。

为什么不立即换 P2+QBind：完整 LoCoMo-Refined 861 题两者均为 **743/861（86.30%）**，14 胜、14 负，尚无净收益，所以默认保留 P2。

仍需提升的是摘要、冲突处理和规则应用。官方 Smoke 已通过，得分 66.39。

队友可从三个方向接着做：更准确的主体/事件绑定；补证是否真正覆盖缺口；撤回识别的鲁棒性。每次只改一个点，先查退步题，再做同库配对。这样更容易判断改动是否有效。
