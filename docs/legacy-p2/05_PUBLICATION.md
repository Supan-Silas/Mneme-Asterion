# 如何同步GitHub并用于AML提交

核对日期：2026-10-24。官方在线文档 https://agentmemories.ai/zh-cn/docs 目前显示材料截止2026-10-31 23:59、评测停止2026-11-04 23:59（UTC+8）。所附8页PDF主要是接口规范，不包含这两个截止时间。建议内部仍留出审核和故障缓冲。

没有找到“必须今天上传P2”的规定。但开源参评材料要求公开仓库、固定commit、来源及改动说明，与自托管的固定接口版本对应。正式提交前，将仓库更新到对应的P2版本即可。

建议沿用 https://github.com/Supan-Silas/Mneme-Asterion ：

1. 保留v0历史，不强推覆盖。当前本地公开仓库HEAD为a2f9ca273caa237025add32ea181d5b30a7a45d4；本次网络读取公共README失败，不能据此确认远端仍停留该commit。
2. 新建P2发布分支。推荐先将本完整服务放在 `systems/p2/`，根README明确P2是当前候选及启动目录，旧根app/标为v0。避免直接混覆盖导致队友仍启动旧AMI。
3. 提交本包代码、简明方法、实验汇总、来源和验收。不要提交.env、密钥、数据库、官方评测原始记忆/题目或金标；公开数据实验也只附汇总，原数据按各源许可另行取得。
4. 队友审阅后合并，记录完整Git commit，建立例如 `p2-20261024` tag。包SHA只是源码校验，不是Git commit，必须以实际发布产生的commit填写材料。
5. 平台版本p2、线上源码和提交commit对应，更新仓库/变更/容量说明；不要只改版本名而运行不同算法。固定版本后再Full；正式Full受理后不能因低分换版或撤回。

本次仅准备本地交付，不自动push、修改在线p2或启动Full。提交说明中应包含固定状态提示NOTICE的机制。

官方PDF第1页要求开源方法Embedding为text-embedding-v4、LLM组件为gpt-4o-mini；本包按这两个模型配置。

PDF第7页对官方评测数据规定用途/访问限制及完成后30天内删除，延长需书面同意。源码发布不需要附这些数据。本包不含官方原始评测数据；线上数据清理另行安排，不在这里自动删除现有审计证据。

验收及发布状态见ACCEPTANCE.md。
